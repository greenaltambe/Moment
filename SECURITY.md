# Security Policy

The Moment Project takes the security and privacy of its users seriously. As a local-first browser extension that handles website navigation policies, we strive to maintain the highest standards of code safety, content security, and isolation.

---

## Supported Versions

Security updates are actively applied to the latest release:

| Version | Supported |
| :--- | :--- |
| 1.2.x | Yes |
| < 1.2.0 | No |

---

## Reporting a Vulnerability

If you discover a security vulnerability in Moment, please report it responsibly:

1. **GitHub Security Advisory (Preferred)**:
   Submit a private report via the repository's **Security** tab under **Report a vulnerability**. This allows secure coordination before public disclosure.
2. **Issue Tracker (Fallback)**:
   If private reporting is unavailable, please open an issue requesting security contact details without including sensitive exploit payloads in the public issue description.

### What to Include
* A clear description of the vulnerability.
* Steps to reproduce or proof-of-concept code.
* The affected browser environment (e.g., Firefox Desktop, Chrome, Firefox Android).
* An assessment of potential impact (e.g., policy bypass, memory leak, CSP violation).

We commit to acknowledging reports promptly and coordinating a fix and disclosure timeline.
